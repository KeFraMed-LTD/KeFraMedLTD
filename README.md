# KeFraMed LTD Website

This is the official website for KeFraMed LTD, a trusted supplier of medical consumables and healthcare essentials in Kenya. The website is built with:

- HTML, CSS, JavaScript
- Bootstrap 5 for responsive design
- AOS (Animate On Scroll) library for scroll animations
- Fully mobile-friendly and optimized for GitHub Pages
